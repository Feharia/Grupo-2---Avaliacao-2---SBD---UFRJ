# Suíte pequena de I/O — plano de implementação

**Goal:** comparar leituras/escritas de duas revisões com protocolo reproduzível.
**Architecture:** reutilizar `bancada --rapido --tuplas`, referência SQLite e
guard de cobertura. Python executa builds/medições isolados e compara CSVs;
  um probe C++ imprime a configuração pública efetivamente compilada. O mesmo
  fonte de driver é compilado contra cada biblioteca e seus respectivos headers.
**Tech Stack:** C++20, CMake, Python padrão, GitHub Actions Ubuntu 24.04.
**Spec:** contrato abaixo, decorrente da autorização do usuário de 13/11.

## Contrato e restrições

- Mesmos dados, esquema, constantes, consultas e lotes, verificados por SHA256;
  mesma escala, semente, repetições, M, compilador/flags e Config (blocos,
  extents, quatro áreas, prefetch/toss). As duas políticas LRU e MRU.
- Verificar ambos os lados com SQLite e tuplas antes de registrar a medição.
  Parear inventário completo de linhas; caso ausente, duplicado, mudança de
  status ou resultado divergente invalida a comparação, sem omissão silenciosa.
- Inteiros exatos para contadores e checksums. Delta absoluto e percentual
  para leituras, escritas e total, por cenário. Denominador zero: percentual
  indefinido. Flush final separado e total com flush também relatado.
- Aumento de custo é alerta, sem budget bloqueante automático. Erro de
  correção, protocolo incompatível ou infraestrutura falha explicitamente.
- Janela atual do Monitor: caches invalidados antes da consulta; delta antes
  do flush final. Carga e manutenção não são medidas por esta versão. Não
  alterar motor, contadores, quatro camadas ou a matriz experimental.
- CI: rodar apenas no job normal, reutilizar a biblioteca do build candidato;
  construir somente biblioteca da referência. Inventário versionado de 108
  identidades; registrar flags reais via compile_commands.json. PR compara SHA base com merge testado; push
  compara before/after; criação de branch usa pai; manual permite referência.
- Saídas novas, SHAs/proveniência, CSV/JSON/Markdown e logs em artifacts.
  Sem commit, push, merge ou configuração administrativa remota.
